# 단기매매 규칙 백테스트

눌림목 매수와 박스권(20일 신고가) 돌파 매수 규칙을 미국·국내 주식에 백테스트합니다.

## 실행

```bash
pip install -r requirements.txt
python run.py                      # 미국+국내, 3개 전략 → results/report.md
python run.py --market kr --sensitivity
python run.py --no-market-filter   # 지수 필터 효과 비교
python compare_signals.py          # 돌파 신호 정의 7가지 비교 → results/signals.md
python -m pytest test_engine.py -q # 체결 로직 테스트
```

데이터는 미국은 `yfinance`(수정주가), 국내는 `FinanceDataReader`(네이버 차트)에서 받아 `data_cache/`에 저장합니다.
직접 받은 CSV를 쓰려면 `--csv-dir 폴더`를 주세요 (`종목코드.csv`, 열: Date,Open,High,Low,Close,Volume / 지수는 `^GSPC.csv`, `KS11.csv`).

## 규칙 (모호한 부분을 숫자로 고정한 버전)

공통
- 신호는 t일 종가로 계산하고 t+1일에 체결합니다.
- 시장 필터: 지수 종가가 200일선 위일 때만 신규 진입합니다.
- 유동성 필터: 20일 평균 거래대금이 미국 $2천만, 국내 30억원 이상인 종목만 매매합니다.
- 수량: 거래당 계좌의 1% 손실로 맞춥니다. 종목당 최대 20%, 보유 포지션 총 리스크는 6% 이하, 최대 10종목까지 보유합니다.
- 비용 (편도 기준)
  - 국내: 수수료 0.015%, 매도세 0.20%, 슬리피지 0.1%
  - 미국: 수수료 0.1%, 슬리피지 0.05% (환전 비용·양도세 제외)

| | 1. 눌림목 (`pullback`) | 2a. 돌파 2R (`breakout_2r`) | 2b. 돌파 추적 (`breakout_trail`) |
|---|---|---|---|
| 조건 | 종가>60일선, 20일선이 5일 전보다 높음, 저가 ≤ 20일선+0.5ATR, 종가 ≥ 20일선−1ATR, 10일 고가 대비 1ATR 이상 조정 | 종가 > 직전 20일 최고가, 거래량 ≥ 직전 20일 평균×1.5 | 동일 |
| 진입 | 다음날 전일 고가 돌파 시 (갭이면 시가) | 다음날 시가 | 다음날 시가 |
| 손절 | 진입가 − 1.5ATR | 진입가 − 2ATR | 진입가 − 2ATR, 이후 10일 최저가로 끌어올림 |
| 익절 | 2R에서 절반, 나머지는 종가가 10일선 밑이면 다음날 시가 | 2R 전량 | 없음 (추세 추종) |
| 시간 손절 | 10거래일 내 2R 미도달 시 다음날 시가 | 없음 | 없음 |

보수적 가정
- 갭이 나면 손절가가 아니라 시가에 체결합니다.
- 같은 날 손절가와 목표가가 모두 닿으면 손절로 처리합니다.
- 진입 당일 손절가에 닿으면 손절로 처리합니다.

## 한계
