# ilsangohn.github.io

Source of Ilsang Ohn's homepage, served at https://ilsangohn.github.io.

Plain HTML with one shared stylesheet (`style.css`); no build step.

- `index.html`, `publications.html`, `talks.html`, `teaching.html`: the four pages
- `cv.pdf`: compiled CV
- `teaching/<course>/`: lecture-note PDFs linked from `teaching.html`
